  Protocolo  : ver protocolo.txt para critérios completos por intent
  Pool base  : top-20 por sistema (3 sistemas = até 60 docs únicos por query)
  Augmentação: top-10 por popularidade do artista-alvo / doc-alvo (known-item)

COMO CALCULAR AS MÉTRICAS
  Instalar: pip install ir-measures

  import ir_measures
  from ir_measures import *

  qrels = ir_measures.read_trec_qrels("qrels.tsv")
  run   = ir_measures.read_trec_run("runs/bm25.txt")

  resultados = ir_measures.calc_aggregate(
      [MRR, Bpref@10, nDCG@10, DCG@10, AP, P@10],
      qrels, run
  )
  print(resultados)
